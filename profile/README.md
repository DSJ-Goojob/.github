## About GooJob

GooJob 是企業智慧管理平台。

我們相信，好的企業系統應該給予企業更多自由，而不是限制工作方式。

GooJob 結合 AI 智慧、資料管理與自動化流程，透過 Low-Code 彈性表單與流程設計，協助企業依照自己的需求建立管理系統。

從日常工作流程開始，逐步整合資料、簽核與管理需求，讓企業更容易建立符合自身營運方式的數位管理流程。
